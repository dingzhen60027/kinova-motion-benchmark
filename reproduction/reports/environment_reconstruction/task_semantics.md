# FR3 任务语义、模型与坐标审计

本报告只读核查已有 `paper_constructed_v5`，不启动 GPU、IK、规划或优化。它读取原始 10 个场景和 400 个案例，并以独立 NumPy 刚体变换重算 FK。执行命令、逐案例结果和全部输入 SHA-256 保存在 [task_semantics_evidence.json](task_semantics_evidence.json)；可重跑入口为 [task_semantics_audit.py](task_semantics_audit.py)。输入在审计前后哈希一致。新环境的实现和结果应另存，不能覆盖这些 v5 证据。

## 结论

当前任务已满足论文“右侧随机关节配置到左侧随机末端位姿”的宽泛描述，且真正以路线图 pose map 作为在线 IK 初猜。**不能把当前 FK 诱导目标分布直接判为论文实现错误，也不能把改成下向抓取自动说成更符合论文。**论文没有公开位置、姿态分布、任务框、桌面尺寸、障碍半径/分布框或作者 33 球位置。

可改进的优先项是：以论文 Figure 6 中的几何关系恢复障碍云相对桌面、基座和机器人尺度的布局；固定并公开世界坐标和目标分布；检查环境改变后真实产生了什么任务，而不是按规划成功或论文表格的段数筛题。当前许多任务可以用一条关节直线完成，任务难度与论文表格并不相同。这个观测尚不能把差异唯一归因于目标高度、碰撞球模型或障碍云中的任何一项。

## 1. 原始证据与判定边界

最高优先级为 [正式论文 v1](https://arxiv.org/pdf/2504.10783v1)。本地 PDF SHA-256 为 `579c9917425fe01b583f067d0a1c9702917ccd810584dbac562fcdf9fead51d0`。[原 TeX](https://arxiv.org/src/2504.10783v1) 只补充说明，注释不能覆盖已发表正文。

| 项目 | 论文证据 | v5 实现 | 判定 |
|---|---|---|---|
| FR3 与环境 | VII-A1，PDF p.8；`experiments.tex:16` | 7 自由度、33 球、20 球障碍、box 桌面 | 数量与类型对齐，尺寸/几何未恢复 |
| 任务端点 | 同上 | 右侧关节均匀拒绝采样为 start；独立左侧关节采样的 FK 为 target pose | 符合文字语义，原分布未知 |
| 目标表示 | V-B，PDF pp.6–7 | 同一场景固定 SE(3) 目标，各 roadmap 重新解 IK | 已实现，未偷换成固定终点 q |
| IK 初猜 | V-B | collision set 排除后，按 translation + 0.2 × rotation angle 排序；至多 10 次 | 来源/步骤对齐；权重来自公开实现，次数上限不是论文参数 |

| 桌面、基座、TCP 世界方向 | 未给世界坐标与数值变换 | base=identity，桌顶 z=0；TCP 在 hand 下 z=.1034 m，hand yaw=−π/4 | 官方模型变换可核查，场景坐标为构造 |
| simulation 速度/加速度 | 方程 15 给符号界；±1 明确出现在硬件段落 | simulation 统一 ±1 | 构造假设，不能称恢复原仿真界 |
| 527/1187 碰撞对 | VII-A1 | 268 静态 + 660 动态 = 928 | 已证实不同；不能通过无依据增加 pair 凑数 |

`right`/`left` 是 v5 的配置名字：right 为 world y>0、left 为 world y<0。在 +x 为机器人正前方、+z 向上的右手系里，机器人自身左侧通常是 +y；面对机器人时屏幕左右又相反。论文未定义观察者坐标，因此**当前命名不能单独证明起终点颠倒**。新图应显式画 x/y/z 轴、机器人朝向和相机方向，记录选择，避免靠“左/右”文字推断。

## 2. 对实际 v5 输入的数值核查

审计输入为 `reproduction/runs/20261026T025846.407684Z_paper_constructed_fr3`。以下均来自文件读取和纯 NumPy 计算，不是新跑实验。

- 10/10 start 位于声明的 right TCP box；10/10 target 位于 left box；start 与目标 witness 均在官方关节界内。独立 FK 与保存 target 的最大矩阵元素误差为 **2.22e−16**。
- 400/400 案例 online IK 成功，平均 **1.4975** 次尝试，最多 9 次。保存目标、起点、障碍和最终 IK 关节值未发现跨阶段不一致。**0** 个被接受的 IK 初猜等于隐藏的目标 witness；源码明确从 roadmap node 选初猜。
- IK 终点位置误差最大 **1.742e−5 m**，旋转矩阵 Frobenius 误差最大 **1.965e−4**，符合当前接受规则。不要把接受规则说成原论文给出的精度。
- 当前 10 个目标高度范围 **0.346–0.949 m**，均值 **0.739 m**；起点高度范围 **0.245–0.932 m**，均值 **0.639 m**。4 个目标和 4 个起点分别高于其场景最高球障碍的顶部；计数对象可重叠。
- 6/10 个目标 TCP 的局部 z 轴有正 world-z 分量；0/10 位于 world-down 的 30° 锥内。这是当前任务分布的描述。论文 Figure 6 的单个姿态例子不足以推导整个 benchmark 都是下向 grasp。
- 当前 20 球在 `x=[.25,.75], y=[−.4,.4], z=[.15,.8] m` 独立均匀散布，半径 .05 m；10 场景共有 **25 对球重叠**。论文只说随机散布，未规定球不重叠，因此不能无依据去重后仍称同一采样分布。
- 400 个案例包含 393 个 DRM 成功和 7 个 DRM 失败。成功路径平均 **1.8499 段、6.4214 rad**；**188/393（47.84%）仅 1 段**。论文对应均值为 4.49 段、8.55 rad。不能按段数、路径长度、碰撞率或优化成功重新选这 10 个环境。

## 3. 模型与桌面具体状况

当前 33 球由 [官方 prepublication FR3 描述固定 commit](https://github.com/frankarobotics/franka_description/tree/7aeeddc449edf8d62b594f9e36a81da53e7796f9) 构造；不是作者发布的本论文模型。球数分配为 link0–7 各 **5/4/3/2/2/6/2/2**、hand 3、两 finger 各 2，总计 33。保留官方 SRDF 过滤和关节限位：

| 关节 | 下界 rad | 上界 rad |
|---|---:|---:|
| 1 | −2.7437 | 2.7437 |
| 2 | −1.7837 | 1.7837 |
| 3 | −2.9007 | 2.9007 |
| 4 | −3.0421 | −0.1518 |
| 5 | −2.8065 | 2.8065 |
| 6 | .5445 | 4.5169 |

桌面 box 尺寸为 **1.4×1.6×.1 m**，中心 **(.5,0,−.05)**，world x 范围 [−.2,1.2]，y 范围 [−.8,.8]，桌顶 z=0。基座位于桌顶的后部，base 姿态为 identity。两 finger 的固定关节各偏移 .04 m；这不是运动自由度，也不应把 `.04` 直接解释为两指之间的总开度。

能够实际改善环境还原的工作：

1. 将论文图中的桌面/机器人/球障碍相对布局与具备真实机械尺寸的官方模型放在同一个坐标系比较；像素估计只形成带范围的构造约束，不能冒充标定数值。
2. 对拟合的球模型分别量化真实 mesh 覆盖和额外膨胀，检查关节运动中的 self collision。官方 SRDF 是合理参考，但不是作者私有过滤的证明。单纯复用 same-model Native/Drake 一致性不能验证物理模型准确性。
3. 显式保存每个 pair 的对象和过滤原因；动态 33×20=660 可精确实现。论文静态 527 的表示/计数未恢复，不能仅凭总数反推唯一过滤。
4. 保留现有官方限位和机械变换，除非获得原始模型证据；不要为增加路径长度而缩窄关节范围或移动基座。

## 4. 不用规划结果筛题的任务生成方案

以下为可直接实施的新协议设计，不是宣称已经执行。场景几何值应由独立 Figure 6/官方机械几何审计确定，并在生成任务前锁定。不存在证据支持的值必须标记为 construction。

**主任务族：reachable-pose tabletop traversal。**保留右侧关节配置到左侧 SE(3) 目标的语义。

1. 每个环境依次生成 obstacle cloud、start、target，用独立 `SeedSequence([paper_id, protocol_version, environment_seed, stream_id])`。固定 10 个未使用的环境 seeds，例如 100–109；调试与正式任务使用不同编号。不能因失败改 seed。
2. start 从官方关节界均匀采样，仅按预先声明的静态/动态碰撞自由、right TCP 区域和数值可表示性接受。选择第一个通过者；拒绝条件不能包含 A*、EI-ZO、轨迹优化或其近似可行性。
3. target 在独立 stream 中按同样的配置分布采样，仅按 left TCP 区域及端点几何自由接受，然后固定其完整 FK 位姿。保存 witness 作为来源核查，在线 IK 不得使用。不要把目标以“接近时采用原 witness”作为兜底。
4. 限额固定且严格，例如每侧 200000 proposals。保存每个被检验 proposal 的顺序和拒绝类别/计数；区分实际生成的 batch 数和找到第一个候选之前已检查的样本数。限额耗尽作为任务生成失败保留，不能静默补题。
5. 同一场景目标在 10 roadmap seeds ×4 sizes 间保持完全一致。每个 roadmap 由它自己的 collision-free pose map warm-start IK；IK 找不到则保留失败。每个方法使用该案例相同的最终 q_start/q_goal。
6. 在第一次跑规划前导出 scene manifest、配置/资产/hash、固定 camera view、所有任务的起终点与障碍静态图。每个方法随后消耗这些固定输入；不允许改场景去修复失败。

**分布歧义的独立诊断族。**如果要检验原文字面上的 Cartesian 随机 pose，可另建一个公开的 diagnostic family：position 在声明 left box 均匀采样，orientation 由三个独立 U[0,1] 生成 Haar-uniform 单位 quaternion；每个任务只取一个固定 pose，不按 IK 成功重抽。这能暴露不可达目标率，但没有原分布证据，不能自动取代主任务族并称“更精确的论文复现”。如果要重建下向抓取，将 tilt/yaw 支持域明确写成独立 pick-and-place family；不要把这项额外假设隐藏在主 benchmark。

## 5. 必须保存的验收指标

| 阶段 | 验收或记录内容 | 不允许的替代 |
|---|---|---|
| 几何 | 7 DOF、33 有效球、20 障碍、table box；官方 FK/限位/固定变换；pair inventory；mesh 覆盖/膨胀；所有坐标可视化 | 用 1187 总数冒充物理模型等价 |

| 任务分布 | xyz/姿态分布、离障碍/桌面的高度、各关节范围；所有 10 场景展示 | 只显示一个“像论文”的漂亮场景 |

| 方法公平性 | 同一 case 的 q_start/q_goal/障碍/model 哈希相同；所有方法共享固定输入 | 对不同方法用不同的 IK 解或重采目标 |
| 论文对照 | 同时报告 all scheduled 与 DRM-success 条件分母；不同版本分别列出 | 把几何、分布、solver 同时变化解释为单一改进 |

对段数和成功率应先报告偏差，不给出“必须落在论文均值 ±x%”的生成验收阈值；这会把结果信息变成筛题规则。确实需要环境敏感性时，先锁定有限几何范围及独立 calibration seeds，报告所有条件，再在未看过的固定 seeds 上运行。最终仍要标注作者原环境未完整恢复。
